# 발견한 이슈 기록법 — `docs/detected_issues.md`

무엇을 여기 적는지는 `core.md` §4. 이 파일은 양식과 사후 처리다.

## 양식

```markdown
- [ ] **한 줄 제목** (발견일 YYYY-MM-DD)
      - 현상과 영향. 안 고치면 무엇이 곤란한지까지 한 문장으로
      - 근거: <Card·코드 경로> · **여쭤볼 것**: <선택지 형태로>
```

- **세 줄을 넘기지 않는다.** 한 번에 여러 건을 놓고 여쭙는 목록이라 길면 못 읽는다
- 상세 서술·실측치는 Card·이슈 원고에 두고 여기서는 경로만 건다
- **여쭤볼 것은 선택지로 적는다** — "어떻게 할까요"가 아니라 "A / B / C 중 무엇으로 할까요"

## 결정된 뒤

1. 체크박스를 `[x]` 로 바꾸고 **결정 내용과 날짜**를 한 줄 덧붙인다
2. 항목을 「결정됨」 섹션으로 옮긴다 — **지우지 않는다**
3. 할 일이 생겼으면 **버그는 {{issueTool}} 이슈, 작업은 Card** 로 등록하고 번호·경로를 적는다(`core.md` §4).

## 주의

- `docs/` 는 git 미추적이다. 사내 정보를 적어도 되지만 **커밋 대상이 아니다**
- 이슈를 적었다고 작업이 끝난 것이 아니다. 그날 일일 리포트에도 발견 사실을 남긴다
