오늘의 일일 리포트를 작성한다.

## 절차

1. 오늘 날짜를 확인한다.
2. `docs/reports/daily/{YYMMDD}.md` 를 만든다. **이미 있으면 덮어쓰지 말고 이어서 갱신한다.**
3. 이 세션에서 실제로 한 작업·결정을 근거로 채운다. **추측으로 채우지 않는다.**
4. 끝나지 않은 작업은 `docs/card/` 의 미완료 할 일을 확인해
   「이어서 할 일」에 모은다. 「오늘 작업한 내용」에는 **어느 카드의 일인지** 드러나게 적는다 —
   주간 보고가 그 주에 손댄 카드를 여기서 가린다.

## 형식

```markdown
# {YYYY-MM-DD} 일일 리포트

## 결정한 것

| 언제 | 어디서 | 무엇을 | 어떻게 | 왜 |
|---|---|---|---|---|
| | | | | |

## 오늘 작업한 내용

- 항목 (완료 시각)

## 이어서 할 일

- [ ] 항목
```

## 규칙

- **간단하게 쓴다.** 한 항목은 한 줄. 상세 설명·실측치는 Card·이슈 원고에 두고 여기서는 경로만 가리킨다.
- 「결정한 것」에 **「누가」는 적지 않는다** — 작성자 본인으로 고정이다.
- 이미 있는 리포트에 이어 쓸 때는 **같은 내용을 다시 적지 않는다.** 값이 바뀌었으면 갱신한다.
- 결정 사항이 없으면 「결정한 것」 표를 비우지 말고 **"없음"** 이라고 적는다.
- 날짜·시각 표기는 `.claude/rules/docs-format.md` 를 따른다 —
  파일명 `YYMMDD`, 문서 내부 `YYYY-MM-DD`, 시각 `YYYY-MM-DD 오후 5:24`.
- 「이어서 할 일」은 **문서 말미**에 둔다.
