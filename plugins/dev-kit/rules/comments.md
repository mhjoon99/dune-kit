# 주석 규칙 (dev-kit)

코드를 쓰거나 고칠 때 주석은 아래를 따른다. 프로젝트의 CLAUDE.md 나 `.claude/rules/` 에 다른 주석 규칙이 있으면 그쪽이 우선이다.

| 위치 | 길이 | 적는 것 |
|---|---|---|
| 파일 머리 | 제한 없음 | 이 파일이 무엇을 하는지, 구성 |
| 함수·클래스 머리 | 1~5줄 | 무엇을 하는지, 입력·출력, 예외 |
| 코드 줄 사이 | 1~2줄 | 코드만 봐서는 모르는 이유·함정 |

쓰지 않는 것:

- 날짜·결정 번호·변경 이력·사고 경위 — git 이 갖고 있다
- 통계·실험 근거
- 코드가 이미 말하는 것을 되풀이하는 설명
- 다른 파일의 요약 — 경로만 적는다

기존 주석이 이 규칙에 어긋나도 맡은 일의 범위 밖이면 고치지 않는다. 주석만 정리해 달라는 요청은 `comment-analyzer` 에이전트로 점검하고, 고칠 안을 사용자에게 확인받은 뒤 수정한다.
