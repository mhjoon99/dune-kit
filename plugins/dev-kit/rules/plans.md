# 플랜 규칙 (dev-kit)

플랜은 착수 전에 어떻게 할지 짜서 사용자에게 확인받는 문서다.

- **언제 쓰는가**: 새 기능이거나 고칠 파일이 3개 이상이면 쓴다. 한두 군데 수정이면 쓰지 않는다. 경계가 애매하면 근거를 붙여 "플랜을 쓸까요" 를 묻는다.
- **어디에 쓰는가**: `docs/plans/` 아래 폴더에 쓰고 컨펌받는다. 컨펌 뒤에는 범위를 넓히지 않는다. 컨펌은 착수 지시가 아니다 — 착수는 따로 지시받는다.
- **사용자가 읽을 문서**(다음 할 일·인계·정리)는 플랜이 아니다. `docs/plans/` 바로 아래에 낱개 파일로 둔다.
- **형식과 짜는 순서**(탐색 → 딥인터뷰 → 초안 → 컨펌, 차수 계획표, 파일명, 완료 표시, 검증, 이동)는 `plan-docs` 스킬을 따른다. 플랜을 쓰거나 고치기 전에 그 스킬을 먼저 읽는다.
